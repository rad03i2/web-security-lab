# Web Security Lab

A safe educational lab for learning defensive web security concepts.

## Focus

- Safe output encoding
- Password policy checks
- CSRF token concept
- Security headers checklist

## Stack

`HTML` · `JavaScript` · `PHP` · `Web Security`

## Important

This repository is defensive and educational. It does not include attack automation or tools for unauthorized access.
